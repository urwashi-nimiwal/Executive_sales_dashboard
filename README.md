# Sales Data Analysis & Power BI Dashboard

## 📌 Project Overview

This project focuses on analyzing sales data using **Python, Pandas, and Power BI** to identify important sales trends, business performance, and key insights.

The data was cleaned and analyzed using Python, and the final insights were presented through an interactive Power BI dashboard.

## 🛠️ Tools & Technologies

* Python
* Pandas
* Matplotlib
* Power BI
* Excel/CSV
* SQL

## 📊 Project Workflow

1. Collected and imported the dataset.
2. Cleaned and prepared the data using Python.
3. Performed exploratory data analysis (EDA).
4. Analyzed sales trends and business performance.
5. Created visualizations using Python.
6. Built an interactive Power BI dashboard.
7. Derived useful business insights from the analysis.

## 📈 Dashboard

The Power BI dashboard provides an interactive view of important business metrics such as:

* Total Sales
* Total Profit
* Sales by Category
* Sales by Region
* Sales Trends
* Product Performance

## 🎯 Key Objective

The main objective of this project is to transform raw sales data into meaningful insights that can support **data-driven business decisions**.
